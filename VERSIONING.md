# Auto Sprint+ 1.4 versioning (Minecraft 26.2)

Build:

    ./gradlew clean build -Ptarget_mc=26.2

The output JAR is placed in `build/libs/` and includes the Minecraft version in its filename:
`Auto-SprintPlus-1.4-26.2.jar`.

Profile values (Minecraft, Loader, Fabric API) are in `versions/26.2.properties`.
