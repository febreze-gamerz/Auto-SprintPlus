# Auto Sprint+ 1.2 — Minecraft 1.21

Fabric client-side mod ported to Minecraft 1.21.

## Kept features
- Auto Sprint toggle
- Y key opens the configuration GUI
- Configurable toggle keybind in Minecraft Controls
- Minecraft-style configuration GUI
- HUD with background, border, colors, opacity, rounded corners and text scale
- HUD editor with grid, snap, center snap, edge snap and scale controls
- HUD position survives GUI-scale changes
- Existing icon and resource layout

## Build
Use Java 21.

Run:
```bash
./gradlew build
```

The remapped mod JAR is configured to be named:

`Auto-SprintPlus-1.2-1.21.jar`

Minecraft target: `1.21`
Fabric Loader: `0.16.5`
Fabric API: `0.102.0+1.21`
Yarn mappings: `1.21+build.9`
